# LoRa Qt 上位机（C++）

此功能包运行在**另一台电脑**上，通过该电脑的 LoRa 串口向车端发送 6 字节控制帧：启动/停止和红球/蓝球选择。当前车端不读取单片机回传数据，也不经 LoRa 转发浮点数据。上位机仍保留浮点帧显示功能，供连接其他数据源或演示模式使用。

上位机不需要订阅车端的 ROS 话题；控制帧走 LoRa 串口。界面使用 C++、Qt Widgets 和非阻塞串口事件通知。

## 数据格式

- 可解析的浮点数据格式：`AA N [N 个小端 float32] 55`，`N` 为 1～64。当前车端不发送此格式。
- 发送控制：`A5 5A 01 sequence flags checksum`。`flags` 的 bit 0（key1）为 1 时启动、0 时停止；bit 1（key2）为 0 时选红球、1 时选蓝球。校验是前 5 字节异或。启动按钮第一次按下保持 1，再按一次变为 0。状态每 200 毫秒重发；串口断开和重连不会自动改变当前启停和颜色选择。

串口默认填 `/dev/ttyUSB0`、9600 波特率。点击设备栏的下拉箭头可选择已连接的 `/dev/ttyUSB*`、`/dev/ttyACM*` 或 `/dev/serial/by-id/*` 设备；每次展开列表时会自动刷新，也可点击“刷新设备”。仍可直接输入设备路径。必须与车端 LoRa 模块的串口波特率以及两端无线模块的配置一致。

`ball_tracking.launch.py` 中的 `LORA_LINK_TIMEOUT_S` 控制按键多久未到达才判离线。离线时保留最后一次有效按键状态，球控不会自动退出启动状态；收到新的停止指令后才停止。

## 在另一台 ROS 2 Humble 电脑上构建

将 `ball_lora_dashboard` 文件夹复制到该电脑的 ROS 2 工作空间 `src/` 下，然后安装 Qt 开发库并构建：

```bash
sudo apt install qtbase5-dev libzip-dev
source /opt/ros/humble/setup.bash
cd ~/your_ws
colcon build --packages-select ball_lora_dashboard
source install/setup.bash
ros2 run ball_lora_dashboard ball_lora_dashboard
```

运行后选择 LoRa 串口设备，点击“连接”。底部可切换启动/停止，并独立选择红球或蓝球。左侧数值和右侧曲线仅在接入发送浮点帧的其他数据源或演示模式时更新；当前车端不会提供这类数据。串口断开后可重新连接。

曲线横轴按接收时间绘制，刻度固定在整秒或整分钟，不会随每帧重新分配；放大到几秒内时显示毫秒。图表和 Excel 导出记录都只保留最近 5 分钟的数据。曲线下方的时间轴滑块可以查看历史并返回实时。鼠标悬停可查看对应帧的时间和各通道数值；滚轮在指针位置缩放，左键框选一个范围放大，右键拖动查看历史，双击或点击“回到实时”恢复自动跟随。左侧可逐路勾选、选择前 8 路或清空选择；点击曲线图例也可隐藏对应通道。

点击“保存图像”可将当前曲线视图保存为 PNG。

点击左侧“导出 Excel”可在后台保存真正的 `.xlsx` 工作簿。每行是一帧，包含接收时间、帧号和 `num1` 等数值；表头已冻结并可筛选。导出范围为本次连接或本次演示中最近 5 分钟，与当前曲线缩放范围无关。

不接硬件也可预览界面和曲线：`ros2 run ball_lora_dashboard ball_lora_dashboard --demo`。演示模式每 50 毫秒生成一帧 5 路模拟浮点数据，界面中“连接真实串口”按钮可切换到真实设备；演示时控制按钮不可用。

上位机可解析的浮点帧不包含照片或视频；界面的“图像”是数值图表和曲线。此格式没有校验字段，传输错误可能导致数值变化或整帧丢弃。
