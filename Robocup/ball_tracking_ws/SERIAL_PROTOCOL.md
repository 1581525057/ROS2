# 小球目标、启停与姿态串口协议 v3

串口节点订阅 `/ball/target_msg`（`ball_tracker_interfaces/msg/BallTarget`）、`/euler_angles`（`geometry_msgs/msg/Vector3`）和 `/lora/keys`（`std_msgs/msg/String`），以默认 115200 波特率向单片机发送固定 **38 字节**数据帧。每收到一帧 IMU 数据就立即发送一次，使用最近的球目标；视觉推理速度不会限制角度更新。独立定时器还持续按 `send_hz`（默认且最低 100 Hz）发送最近状态。LoRa 启停变化也会立即触发发送。

## 小电脑发送给单片机

| 字节偏移 | 长度 | 内容 |
| --- | ---: | --- |
| 0 | 1 | 帧头 `0xAA` |
| 1 | 1 | 协议版本 `0x03` |
| 2 | 1 | 整帧长度 `0x26`（38） |
| 3 | 1 | 状态位 `flags` |
| 4–7 | 4 | `error_x_norm`，小端 IEEE 754 `float32` |
| 8–11 | 4 | `error_y_norm`，小端 IEEE 754 `float32` |
| 12–15 | 4 | `area_ratio`，小端 IEEE 754 `float32` |
| 16–19 | 4 | `width_norm`，小端 IEEE 754 `float32` |
| 20–23 | 4 | `height_norm`，小端 IEEE 754 `float32` |
| 24–27 | 4 | `roll_deg`，横滚角（度），小端 `float32` |
| 28–31 | 4 | `pitch_deg`，俯仰角（度），小端 `float32` |
| 32–35 | 4 | `yaw_deg`，偏航角（度），小端 `float32` |
| 36 | 1 | 校验和：字节 **1 到 35** 相加，取低 8 位 |
| 37 | 1 | 帧尾 `0x55` |

`flags` 位定义：

- bit 0 (`0x01`)：`camera_ok`，1 为相机成功读帧。
- bit 1 (`0x02`)：`detected`，1 为找到所选球。
- bit 2 (`0x04`)：所选颜色，0 为红球，1 为蓝球。
- bit 3 (`0x08`)：三个欧拉角均为新鲜且已提供的数据；为 0 时角度字段为 0，接收端必须忽略。
- bit 4 (`0x10`)：启动标志；保持最后一次收到的有效 key1 状态。key1=1 时为 1，下一次 key1=0 时才变为 0；LoRa 掉线不改变此位。
- bit 5–7：保留，当前均为 0。

LoRa key1 是保持状态的启停开关：第一次按下变为 1 并保持启动，再按一次变为 0 才停止。key2=0 选红球、1 选蓝球，与 key1 状态无关。收到新的颜色选择后，旧颜色的视觉结果会失效，直到收到对应颜色的新结果。LoRa 掉线或没有新控制消息时保留最后一次有效的启动位和颜色；节点刚启动且尚未收到有效控制时，启动位为 0。

`detected=0` 或启动位为 0 时五个球目标 `float32` 全部发送 0，单片机必须忽略这些位置与大小值并停止沿用上次目标；有效的 IMU 角度仍会发送。相机离线时 bit 0 和 bit 1 都是 0。视觉节点超过配置的 `stale_timeout`（集成启动默认 1.5 秒）不发布消息时，目标字段清零，但启动位不变。IMU 数据超过 `imu_stale_timeout`（默认 0.5 秒）时，角度字段清零且 bit 3 置 0。单片机还应在连续 0.5 秒收不到有效帧时自行停止追踪。

FDILink 驱动在 `/euler_angles` 发布 roll、pitch、heading 弧度值，发送前换算成度。bit 3 只表示三个角度数值有限且未超过 `imu_stale_timeout`，不表示姿态已经收敛。

接收端先找 `0xAA`，再按长度字节读取完整 38 字节，验证版本 `0x03`、长度 `0x26`、帧尾和校验和。单片机接收程序必须同步识别 v3 的启动位。**不要只靠查找 `0x55` 判定帧尾**：浮点数据中也可能出现 `0x55`。数据未通过校验时丢弃该帧，重新寻找下一帧头。

例如相机正常、已经启动、找到红球且角度有效时，状态位为 `0x1B`；找到蓝球时为 `0x1F`。停止时 bit 4 与 bit 1 均为 0，球目标数值全零。单片机可用 `error_x_norm` 转向，用 `area_ratio` 等图像大小指标估算接近程度；这些指标不是以米为单位的距离。
