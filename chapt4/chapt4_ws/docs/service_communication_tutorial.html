这份教程带你从零创建一个 ROS 2 服务通信例子：客户端请求机器人去某个房间，服务端根据参数决定是否接受任务。你会同时学到 `.srv` 格式、服务端、客户端、参数回调、参数事件监听和远程修改参数。

1. 学习目标

学完后，你要能看懂并自己写出下面这条 ROS 2 Service 链路：

  • 创建 `srv/PatrolTask.srv` 服务接口文件。
  • 配置接口包，让 ROS 2 生成 Python 可导入的服务类型。
  • 写一个服务端节点 `patrol_server`。
  • 写一个客户端节点 `patrol_client`。
  • 用参数 `robot_name` 和 `allow_task` 控制服务端行为。
  • 监听 `/parameter_events`，观察参数变化。
  • 写一个节点远程修改 `/patrol_server` 的参数。
  • 用 `ros2 run`、`ros2 param` 和 `ros2 interface` 验证结果。
先记住一句话 Service 就是一问一答：客户端填写 Request，服务端填写 Response。

2. 先看懂 Service

ROS 2 里常见通信方式有三种。刚开始不用背概念，先看使用感觉。

通信方式 英文 适合场景 感觉
话题 Topic 一直发数据，例如速度、雷达、图像 一直广播
服务 Service 问一次，答一次，例如查询状态、下发简单任务 一问一答
动作 Action 长时间任务，例如导航，可以反馈进度 下任务，看过程

这篇只讲 Service。我们的例子是：

业务例子
客户端：请机器人去 room_A。
服务端：读取参数 allow_task。
如果 allow_task 是 true，接受任务。
如果 allow_task 是 false，拒绝任务。

Service 的流程可以理解成：

Service 流程
客户端创建 request
客户端发送 request
服务端收到 request
服务端填写 response
服务端返回 response
客户端拿到 response

3. 定义 srv 接口

`.srv` 文件专门描述 Service 的 Request 和 Response。我们要创建：

文件位置
src/chapt4_interfaces/srv/PatrolTask.srv

文件内容如下：

PatrolTask.srv
string target_name
---
bool accepted
string message
怎么读 srv 文件 `---` 上面是 Request，客户端发给服务端；`---` 下面是 Response，服务端返回给客户端。
字段 属于谁 含义
`target_name` Request 客户端告诉服务端目标点名字，例如 `room_A`。
`accepted` Response 服务端告诉客户端是否接受任务。
`message` Response 服务端返回一句说明。

7. 服务端节点

创建文件：

文件位置
src/patrol_service_demo/patrol_service_demo/patrol_server.py

完整代码：

patrol_server.py
import rclpy
from chapt4_interfaces.srv import PatrolTask
from rcl_interfaces.msg import SetParametersResult
from rclpy.node import Node


class PatrolServer(Node):
    def __init__(self):
        super().__init__('patrol_server')

        self.declare_parameter('robot_name', 'robot_01')
        self.declare_parameter('allow_task', True)

        self.add_on_set_parameters_callback(self.on_parameter_update)

        self.service = self.create_service(
            PatrolTask,
            'patrol_task',
            self.handle_patrol_task,
        )

        self.get_logger().info('patrol_task service is ready')

    def on_parameter_update(self, parameters):
        for parameter in parameters:
            if parameter.name == 'robot_name' and parameter.value == '':
                return SetParametersResult(
                    successful=False,
                    reason='robot_name cannot be empty',
                )

        return SetParametersResult(successful=True)

    def handle_patrol_task(self, request, response):
        robot_name = self.get_parameter('robot_name').value
        allow_task = self.get_parameter('allow_task').value

        if allow_task:
            response.accepted = True
            response.message = robot_name + ' accepted target: ' + request.target_name
        else:
            response.accepted = False
            response.message = robot_name + ' rejected target: ' + request.target_name

        return response


def main(args=None):
    rclpy.init(args=args)
    node = PatrolServer()

    try:
        rclpy.spin(node)
    finally:
        node.destroy_node()
        rclpy.shutdown()


if __name__ == '__main__':
    main()

服务端代码怎么读

导入服务类型

`from chapt4_interfaces.srv import PatrolTask` 导入自己定义的 `.srv` 类型。没有前面接口包的构建，这句会失败。

声明参数

`robot_name` 默认是 `robot_01`，`allow_task` 默认是 `True`。参数不是普通变量，它可以在节点运行时用命令修改。

注册参数回调

`add_on_set_parameters_callback()` 表示别人修改本节点参数前，先进入 `on_parameter_update()` 检查。

创建服务

`create_service(PatrolTask, 'patrol_task', self.handle_patrol_task)` 表示创建一个名叫 `patrol_task` 的服务。客户端调用它时，ROS 2 自动执行 `handle_patrol_task()`。

填写响应

`request.target_name` 来自客户端；`response.accepted` 和 `response.message` 由服务端填写并返回。

8. 客户端节点

创建文件：

文件位置
src/patrol_service_demo/patrol_service_demo/patrol_client.py

完整代码：

patrol_client.py
import rclpy
from chapt4_interfaces.srv import PatrolTask
from rclpy.node import Node


class PatrolClient(Node):
    def __init__(self):
        super().__init__('patrol_client')

        self.declare_parameter('target_name', 'room_A')

        self.client = self.create_client(PatrolTask, 'patrol_task')

    def send_request(self):
        while not self.client.wait_for_service(timeout_sec=1.0):
            self.get_logger().info('waiting for patrol_task service...')

        request = PatrolTask.Request()
        request.target_name = self.get_parameter('target_name').value

        future = self.client.call_async(request)
        rclpy.spin_until_future_complete(self, future)

        response = future.result()
        self.get_logger().info('accepted: ' + str(response.accepted))
        self.get_logger().info('message: ' + response.message)


def main(args=None):
    rclpy.init(args=args)
    node = PatrolClient()

    try:
        node.send_request()
    finally:
        node.destroy_node()
        rclpy.shutdown()


if __name__ == '__main__':
    main()

客户端代码怎么读

  • `create_client(PatrolTask, 'patrol_task')` 创建客户端。服务类型和服务名字必须和服务端一致。
  • `wait_for_service()` 会等待服务端启动。如果服务端没开，客户端会一直打印等待信息。
  • `request = PatrolTask.Request()` 创建请求对象。
  • `request.target_name = ...` 填写 `.srv` 上半部分定义的字段。
  • `call_async(request)` 发送请求。
  • `spin_until_future_complete()` 等待服务端返回。
  • `future.result()` 取出 Response。

9. 节点参数

参数可以理解为“运行时配置”。不用改代码，就能改变节点行为。

参数名 默认值 作用
`robot_name` `robot_01` 服务端回复消息里使用的机器人名字。
`allow_task` `True` 决定服务端接受还是拒绝任务。
`target_name` `room_A` 客户端要发送的目标点。

服务端里这句是参数修改前检查：

参数更新回调
self.add_on_set_parameters_callback(self.on_parameter_update)

它的意思是：

参数修改流程
有人想改参数
  ↓
先进入 on_parameter_update()
  ↓
返回 successful=True，参数才会真的修改
返回 successful=False，参数修改失败

这个例子里，`robot_name` 不允许设置为空字符串。

10. 参数事件监听

当 ROS 2 节点的参数新增、修改、删除时，系统会发布 `/parameter_events` 消息。我们写一个节点专门观察它。

parameter_event_watcher.py
import rclpy
from rcl_interfaces.msg import ParameterEvent
from rclpy.node import Node
from rclpy.parameter import parameter_value_to_python


class ParameterEventWatcher(Node):
    def __init__(self):
        super().__init__('parameter_event_watcher')

        self.subscription = self.create_subscription(
            ParameterEvent,
            '/parameter_events',
            self.on_parameter_event,
            10,
        )

        self.get_logger().info('watching /parameter_events')

    def on_parameter_event(self, event):
        for parameter in event.new_parameters:
            value = parameter_value_to_python(parameter.value)
            self.get_logger().info(
                'new: node=' + event.node
                + ' name=' + parameter.name
                + ' value=' + str(value)
            )

        for parameter in event.changed_parameters:
            value = parameter_value_to_python(parameter.value)
            self.get_logger().info(
                'changed: node=' + event.node
                + ' name=' + parameter.name
                + ' value=' + str(value)
            )

        for parameter in event.deleted_parameters:
            self.get_logger().info(
                'deleted: node=' + event.node
                + ' name=' + parameter.name
            )


def main(args=None):
    rclpy.init(args=args)
    node = ParameterEventWatcher()

    try:
        rclpy.spin(node)
    finally:
        node.destroy_node()
        rclpy.shutdown()


if __name__ == '__main__':
    main()
参数回调和参数事件的区别 `on_parameter_update` 是修改前检查，可以拒绝；`/parameter_events` 是修改后广播，只能观察。

11. 远程修改参数

远程修改参数就是一个节点去修改另一个节点的参数。这里让 `remote_param_setter` 去修改 `/patrol_server`。

remote_param_setter.py
import rclpy
from rclpy.node import Node
from rclpy.parameter import Parameter
from rcl_interfaces.srv import SetParameters


class RemoteParamSetter(Node):
    def __init__(self):
        super().__init__('remote_param_setter')

        self.client = self.create_client(
            SetParameters,
            '/patrol_server/set_parameters'
        )

    def set_remote_parameters(self):
        while not self.client.wait_for_service(timeout_sec=1.0):
            self.get_logger().info('等待 /patrol_server/set_parameters 服务...')

        request = SetParameters.Request()
        request.parameters = [
            Parameter(
                'robot_name',
                Parameter.Type.STRING,
                'robot_02'
            ).to_parameter_msg(),
            Parameter(
                'allow',
                Parameter.Type.BOOL,
                False
            ).to_parameter_msg(),
        ]

        future = self.client.call_async(request)
        rclpy.spin_until_future_complete(self, future)

        try:
            response = future.result()

            for result in response.results:
                if result.successful:
                    self.get_logger().info('远程参数修改成功')
                else:
                    self.get_logger().error(
                        f'远程参数修改被拒绝：{result.reason}'
                    )
        except Exception as error:
            self.get_logger().error(f'调用参数服务失败：{error}')


def main():
    rclpy.init()
    node = RemoteParamSetter()

    try:
        node.set_remote_parameters()
    finally:
        node.destroy_node()
        rclpy.shutdown()


if __name__ == '__main__':
    main()

关键代码是：

参数客户端
self.client = self.create_client(
    SetParameters,
    '/patrol_server/set_parameters'
)

它表示：创建 `SetParameters` 服务客户端，调用 `/patrol_server` 自动提供的参数修改服务。

14. 常见错误

找不到 `chapt4_interfaces`

常见原因是没有构建接口包，或者新终端没有 source。

修复命令
cd ~/ROS2_Repository/chapt4/chapt4_ws
colcon build --packages-select chapt4_interfaces
source install/setup.bash

`ros2 run` 找不到可执行命令

检查 `setup.py` 的 `entry_points`，然后重新构建并 source。

修复命令
cd ~/ROS2_Repository/chapt4/chapt4_ws
colcon build --packages-select patrol_service_demo
source install/setup.bash

客户端一直等待服务

说明服务端没有运行，或者服务名不一致。服务端和客户端都必须使用 `patrol_task`。

检查服务列表
ros2 service list

参数设置失败

如果你设置 `robot_name` 为空，服务端会拒绝，这是代码里故意写的参数检查。

会失败的命令
ros2 param set /patrol_server robot_name ""
最容易忘的事 新终端没有执行 `source install/setup.bash`，是 ROS 2 新手最常见的问题之一。

15. 总结

最后把关键代码再压缩成几句话。

服务端创建服务
self.service = self.create_service(
    PatrolTask,
    'patrol_task',
    self.handle_patrol_task,
)

意思是：服务类型是 `PatrolTask`，服务名字是 `patrol_task`，收到请求后执行 `handle_patrol_task`。

服务回调
def handle_patrol_task(self, request, response):
    response.accepted = True
    response.message = 'accepted target: ' + request.target_name
    return response

`request` 是客户端发来的，`response` 是服务端填写的，它们由 ROS 2 自动传进来。

客户端发送请求
request = PatrolTask.Request()
request.target_name = 'room_A'
future = self.client.call_async(request)

参数相关只记两句：

  • `add_on_set_parameters_callback()` 是修改前检查，可以拒绝。
  • `/parameter_events` 是修改后广播，只能观察。
最终记忆 服务是 Request 和 Response；参数是运行时配置；参数事件是观察配置变化。
